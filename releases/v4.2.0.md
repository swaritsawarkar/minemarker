# MineMarker V4.2 - One-Click Mod Installer and UI Redesign

## Summary

V4.2 makes the desktop app the starting point. Users can download the Windows portable `.exe`, click `Install Minecraft Mod`, and the app copies the bundled MineMarker Fabric mod into the default Minecraft mods folder.

The timeline viewer UI was also redesigned to feel more like a Minecraft creator editing tool and less like a generic dashboard.

## Features

- Bundles `minemarker-2.0.0.jar` inside the desktop app.
- Adds one-click `Install Minecraft Mod` action.
- Copies the mod jar to the default `.minecraft/mods` directory.
- Adds an `Open mods folder` action.
- Keeps local JSON/video loading, offset correction, timeline jumps, suggestions, and exports.
- Redesigns the UI with a setup-first workflow and sharper Minecraft-inspired visual language.

## How Sync Works

1. Download and open `MineMarker-Timeline-Viewer-4.2.0-Portable-x64.exe`.
2. Click `Install Minecraft Mod`.
3. Launch Minecraft with Fabric.
4. Run `/minemarker start episode-1`.
5. Add markers while recording, then run `/minemarker stop`.
6. Load the exported `session.json` in the desktop app.
7. Load the matching OBS/video recording.
8. Use offset correction if recording and MineMarker start times differ.

V4.2 still uses file-based sync. It does not live-stream events from Minecraft into the desktop app yet.

## Installation / Build

Build the Fabric mod:

```powershell
cd minemarker-mod
$env:JAVA_HOME="$env:USERPROFILE\.cache\minemarker-tools\jdk-25"
.\gradlew.bat clean build
```

Build the desktop app:

```powershell
cd timeline-viewer
npm install
npm run desktop:build
```

## Known Issues

- Windows x64 only.
- The `.exe` is unsigned, so Windows may show an unknown publisher warning.
- One-click install targets the default Minecraft directory. Custom launcher directories may need manual jar placement.
- No live Minecraft-to-desktop connection yet.
- In-game Minecraft runtime testing was not performed in this environment.
