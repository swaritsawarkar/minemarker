# MineMarker V4.1.1 - Portable App Hotfix

## Summary

V4.1.1 fixes the Windows portable timeline viewer `.exe`. The previous desktop build could open a window but fail to load the app bundle because Vite emitted absolute `/assets/...` paths. This hotfix uses relative asset paths for Electron local file execution.

This release also clarifies the Minecraft sync model: users need both the Fabric mod jar and the timeline viewer app. The app does not live-connect to Minecraft yet; it reads the `session.json` exported by the mod.

## Features / Fixes

- Fixed Electron desktop asset loading.
- Added in-app Minecraft sync instructions.
- Added clearer docs explaining the mod-to-viewer workflow.
- Uploads both:
  - `MineMarker-Timeline-Viewer-4.1.1-Portable-x64.exe`
  - `minemarker-2.0.0.jar`

## How Sync Works

1. Install `minemarker-2.0.0.jar` in `.minecraft/mods/`.
2. Launch Minecraft with Fabric.
3. Run `/minemarker start episode-1`.
4. Add markers while recording, or let V2 events record stable automatic events.
5. Run `/minemarker stop`.
6. Open the timeline viewer `.exe`.
7. Load the exported `session.json`.
8. Load the matching OBS/video file.
9. Use the offset control if OBS started earlier or later than the MineMarker session.

## Installation / Build

Build the Fabric mod:

```powershell
cd minemarker-mod
$env:JAVA_HOME="$env:USERPROFILE\.cache\minemarker-tools\jdk-25"
.\gradlew.bat clean build
```

Build the desktop app:

```powershell
cd timeline-viewer
npm install
npm run desktop:build
```

## Known Issues

- The `.exe` is unsigned, so Windows may show an unknown publisher warning.
- Windows x64 only.
- No live Minecraft-to-desktop connection yet.
- OBS sync is manual with timestamp offset.
- In-game Minecraft runtime testing was not performed in this environment.
