# MineMarker V3 - Local Timeline Viewer

## Summary

V3 adds a local web timeline viewer for MineMarker exports and recorded video files.

## Features

- React + Vite local app
- Load MineMarker `session.json`
- Load a local video file
- Show manual markers and automatic events on one timeline
- Click timeline ticks or list rows to jump video playback
- Manual offset adjustment
- Filters for all, markers, events, and high-priority moments
- Export `editing_notes.txt`
- Export `editing_markers.csv`

## Build

```powershell
cd timeline-viewer
npm install
npm run build
```

## Run

```powershell
cd timeline-viewer
npm run dev
```

Open `http://127.0.0.1:5173/`.

## Known Issues

- V3 is a web app, not a portable `.exe`.
- Browser file permissions require manual JSON/video selection.
- The viewer does not edit or transcode video.
- Premiere/DaVinci-specific marker formats are deferred to V4.
- NPM reports moderate advisories in dev dependencies; no force upgrade was applied.
