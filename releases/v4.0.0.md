# MineMarker V4 - Creator Export Workflow

## Summary

V4 improves the local timeline viewer with rule-based creator workflow suggestions and richer review exports. This release does not add AI, OBS automation, or verified native editor marker import.

## Features

- Rule-based clip candidate suggestions.
- Rule-based timelapse candidate suggestions.
- Rule-based quiet-section detection for long gaps without markers/events.
- `editing_suggestions.txt` export.
- `editor_review.csv` export.
- Example V4 suggestion and review exports.
- Timeline viewer package version updated to `4.0.0`.

## Installation / Build

Build the Minecraft mod:

```powershell
cd minemarker-mod
$env:JAVA_HOME="$env:USERPROFILE\.cache\minemarker-tools\jdk-25"
.\gradlew.bat clean build
```

Run the timeline viewer:

```powershell
cd timeline-viewer
npm install
npm run dev
```

Build the timeline viewer:

```powershell
npm run build
```

## Usage

1. Export a MineMarker session from Minecraft.
2. Open the timeline viewer.
3. Load `session.json`.
4. Load a local video file if available.
5. Review timeline markers/events and V4 suggestions.
6. Export `editing_notes.txt`, `editing_markers.csv`, `editing_suggestions.txt`, or `editor_review.csv`.

## Known Issues

- V4 suggestions are deterministic rules, not AI analysis.
- `editor_review.csv` is not verified as a direct Premiere, DaVinci Resolve, or Final Cut marker import.
- Timeline viewer remains a web app, not a packaged portable `.exe`.
- In-game Minecraft testing was not performed in this environment.
- GitHub release publication depends on configured GitHub remote/auth.
