# MineMarker V2 - Automatic Event Detection

## Summary

V2 adds safe client-side automatic event detection to the V1 manual marker workflow.

## Features

- Player death event detection
- Dimension change event detection
- Low health warning event detection
- Events exported under `events` in `session.json`
- Events shown in `markers.txt`
- `/minemarker events on`
- `/minemarker events off`
- `/minemarker events status`
- Config fields for event detection

## Deferred Event Types

The following are not implemented in V2 because they need more Minecraft/Fabric `26.1.2` validation before being safe client-side features:

- Advancement unlocked
- Diamond ore mined
- Deepslate diamond ore mined
- Ancient debris mined
- Totem popped
- Boss killed
- Rare item pickup

## Build

```powershell
cd minemarker-mod
$env:JAVA_HOME="$env:USERPROFILE\.cache\minemarker-tools\jdk-25"
.\gradlew.bat clean build
```

## Usage

```text
/minemarker start episode-2
/minemarker events status
/minemarker events off
/minemarker events on
/minemarker stop
```

## Known Issues

- In-game testing was not performed in this environment.
- Event detection is client-side polling, not server-authoritative telemetry.
- Advancement and valuable block detection are deferred.
- OBS sync remains manual.
