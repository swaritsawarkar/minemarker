# MineMarker V4.1 - Portable Desktop App

## Summary

V4.1 packages the MineMarker Timeline Viewer as a Windows x64 portable Electron `.exe`. The web app remains available for local browser use.

## Features

- Windows portable desktop app for the MineMarker Timeline Viewer.
- Local-only JSON and video file loading.
- Timeline markers/events, offset adjustment, filters, and exports from V4.
- Rule-based creator suggestions from V4.
- `npm run desktop:build` packaging script.

## Installation / Build

Run the portable app from the GitHub release asset:

```text
MineMarker-Timeline-Viewer-4.1.0-Portable-x64.exe
```

Build locally:

```powershell
cd timeline-viewer
npm install
npm run desktop:build
```

The generated executable is written to:

```text
timeline-viewer/desktop-dist/MineMarker-Timeline-Viewer-4.1.0-Portable-x64.exe
```

## Usage

1. Open the portable `.exe`.
2. Load a MineMarker `session.json`.
3. Load the matching local video file.
4. Adjust offset if needed.
5. Click markers/events or suggestions to review editing moments.
6. Export notes, marker CSV, suggestions, or review CSV.

## Known Issues

- The `.exe` is unsigned, so Windows may show an unknown publisher warning.
- Windows x64 only.
- No auto-update support.
- The app does not upload files and does not scan the disk automatically.
- In-game Minecraft runtime testing was not performed in this environment.
