# MineMarker V4.3 - Latest Session Loader

## Summary

V4.3 improves the after-recording workflow. The desktop app can now load the newest MineMarker session export automatically with `Load Last Session`, while still supporting manual `Load Custom Session`.

## Features

- Adds `Load Last Session`.
- Finds the newest `.minecraft/minemarker/sessions/*/session.json`.
- Adds `Open sessions folder`.
- Renames manual JSON loading to `Load Custom Session`.
- Keeps one-click mod install from V4.2.
- Keeps local video loading, offset correction, timeline jumps, suggestions, and exports.

## Workflow

1. Open the Windows portable `.exe`.
2. Click `Install Minecraft Mod`.
3. Launch Minecraft with Fabric.
4. Run `/minemarker start episode-1`.
5. Play and record normally.
6. Run `/minemarker stop`.
7. Return to the desktop app.
8. Click `Load Last Session`.
9. Load the matching OBS/video file.
10. Adjust offset if needed.

Use `Load Custom Session` if the export is in a custom folder or from another machine.

## Known Issues

- Latest-session loading targets the default Minecraft folder.
- Custom launcher directories may need manual session loading.
- Sync is still file-based, not live streaming from Minecraft.
- The `.exe` is unsigned.
- In-game Minecraft runtime testing was not performed in this environment.
