# MineMarker V1 - Manual Marker Mod

## Summary

V1 is the first working MineMarker foundation: a Fabric client-side mod for manual creator timeline markers and clean exports.

## Features

- `/minemarker start [session_name]`
- `/minemarker mark <label> [note]`
- `/minemarker stop`
- `/minemarker status`
- `/minemarker export`
- `/minemarker offset <seconds>`
- `/minemarker help`
- `/minemarker list`
- `/minemarker undo`
- Quick marker keybind, default `M`
- JSON/TXT/CSV/session README exports
- Manual video offset support
- Simple config file

## Build

```powershell
cd minemarker-mod
$env:JAVA_HOME="$env:USERPROFILE\.cache\minemarker-tools\jdk-25"
.\gradlew.bat clean build
```

## Install

Copy the built jar from `minemarker-mod/build/libs/` into `.minecraft/mods/` and launch Minecraft Java `26.1.2` with Fabric Loader `0.19.2`.

## Usage

Start OBS, join a world, run `/minemarker start episode-1`, add markers while playing, then run `/minemarker stop`. Use the exported TXT/CSV/JSON timestamps while editing.

## Known Issues

- In-game testing was not performed in this environment.
- Automatic event detection is not implemented until V2.
- OBS sync is manual.
- Biome exports are `null` in V1.
- Server compatibility is not fully tested.
- Keybind may conflict with other mods.
