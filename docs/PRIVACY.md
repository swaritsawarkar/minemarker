# MineMarker Privacy Policy

Effective date: October 10, 2026

MineMarker is a local Windows desktop app and Minecraft Fabric mod.

## Data handling

MineMarker does not require an account and does not collect, sell, transmit, or share personal information. Session JSON files, Minecraft session markers, selected video files, exports, and app settings remain on the user's device. MineMarker does not upload these files to a server.

The desktop app stores the selected Minecraft folder in its local application settings. The Fabric mod writes session exports inside the selected Minecraft folder. Users can remove this data by deleting the MineMarker session folders and uninstalling the app.

## Network access

The installed app does not require MineMarker-operated online services. Links opened from the app are opened in the user's default browser and are governed by the destination site's privacy policy.

## Children

MineMarker does not knowingly collect personal information from children because it does not collect personal information from any user.

## Changes

Material changes to this policy will be published in this repository with a revised effective date.

## Contact

For privacy or support requests, open an issue at https://github.com/swaritsawarkar/minemarker/issues
