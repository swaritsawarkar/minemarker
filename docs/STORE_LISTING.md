# Microsoft Store listing copy

## Product name

MineMarker

## Short description

Turn Minecraft moments into a clean editing timeline with local markers, session loading, and video sync.

## Description

MineMarker helps Minecraft Java creators mark important moments while playing and find them again while editing.

Install the bundled Fabric mod from the desktop app, record a MineMarker session in Minecraft, then load the latest session beside your local video. Click any marker or detected event to jump to that point in the recording, correct timing with a manual offset, filter the timeline, and export editing notes or CSV files.

MineMarker runs locally. It does not require an account, upload videos, or send session data to a cloud service.

## Features

- One-click installation of the bundled MineMarker Fabric mod
- Default or custom Minecraft folder support
- Load the newest MineMarker session or choose a session JSON file
- Play a local recording and jump to marker timestamps
- Manual video offset correction
- Filters for markers, events, and high-priority moments
- Rule-based clip and quiet-section suggestions
- TXT and CSV exports for editing review

## Minimum system notes

- Windows 10 version 1809 or later, x64
- Minecraft Java and Fabric are required for in-game marker creation
- A local video is optional

## Certification notes

MineMarker is a full-trust Electron desktop app. It reads session files and optional videos selected or stored by the user. Its mod installer copies the bundled MineMarker JAR into the user's selected Minecraft mods folder. The app does not install services, drivers, browser extensions, or unrelated software, and it does not require administrator privileges.
